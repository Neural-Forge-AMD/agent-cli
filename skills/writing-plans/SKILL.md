# Writing Implementation Plans

## Guidelines

1. **Understand requirements**: Clarify ambiguities before finalizing plan structure.
2. **Break into atomic steps**: Each step should be testable independently.
3. **Specify file paths**: List exact target files and functions to modify.
4. **Define verification criteria**: Every task must have an automated test or verification step.
